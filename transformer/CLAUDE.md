# Transformer Notebooks

## 概要

書籍「文章生成を実現する数理」（第4章）を軸に、Transformer アーキテクチャの数理を Jupyter Notebook で学習・アウトプットする。

## ノートブック作成ガイドライン

### 前提

- ユーザーから画像（書籍のページ等）やテキストで学習材料が渡される
- 基礎学力や理解力に自信がない人でも理解できるレベルを目指す
- 「読んで終わり」ではなく、コードを動かして体感できるアウトプット型

### 構成ルール

1. **目次を冒頭に置く** — 全体像を最初に把握できるようにする
2. **概念 → 図解 → コード → まとめ** の順で進める
   - Markdown セルで概念を平易に説明
   - コードセルで可視化（matplotlib）して視覚的に理解
   - 最後に要点をまとめる
3. **1ノートブック = 1テーマ** — 詰め込みすぎない
4. **「次のステップ」で次回への橋渡しを書く**

### 説明スタイル

- 専門用語は初出時に必ず日本語で噛み砕いて説明する
- 数式は「何を意味しているか」を日本語で先に説明してからコードで示す
- 表やテーブルを積極的に使って比較・整理する
- 「なぜそうなるのか？」を省略しない
- 具体的な数値例を必ず入れる（抽象的な説明だけにしない）

### コードスタイル

- numpy / matplotlib を基本とする（必要に応じて PyTorch）
- コードにはコメントを多めに書く
- 可視化は日本語ラベル・タイトルを使う
- print 文で計算の途中経過を表示し、何が起きているか追えるようにする

### 既存ノートブックとの統一

- `image_classifier/notebooks/` の CNN シリーズと同じスタイルを踏襲する
- ファイル名は `01_topic_name.ipynb` の連番形式
- セルの粒度: Markdown で説明 → コードで実証、を交互に繰り返す

### 想定トピック（書籍第4章ベース）

```
01: トークンと単語埋め込み (Token & Word Embedding)
02: 位置符号化 (Positional Encoding)
03: 内積とスケーリング (Dot Product & Scaling)
04: Self-Attention
05: Multi-Head Attention
06: Cross-Attention
07: エンコーダ (Encoder)
08: デコーダ (Decoder)
09: Transformer 全体像
```

順番や粒度は学習の進み具合に応じて調整する。
